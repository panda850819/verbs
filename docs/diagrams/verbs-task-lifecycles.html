# One task spine, multiple lifecycles

連貫的是 task state。Skill 在特定狀態介入，交付結果與證據後回到主線。以下六條路徑都是完整 lifecycle，但完成的 task 類型與 Delivery Target 不同。

INTENT→WORK CONTRACT→EXECUTION→ACCEPTANCE EVIDENCE→DELIVERY / CLOSURE

01 · STANDARD CHANGE

一般程式碼變更

Signal：需求清楚，沒有未知設計或未解 failure。

02 · UI DISCOVERY

UI 探索與正式建置

Signal：視覺方向仍開放，需要先用 cheap artifact 做決策。

03 · FAILURE RECOVERY

Bug fix

Signal：failure 已觀察到，root cause 仍未知。

04 · ARCHITECTURE INVESTMENT

架構探索後實作

Signal：知道有架構壓力，但還不知道值得投資的 seam。

05 · CROSS-SESSION DECISIONS

Decision Map

Signal：多個相依決策與證據無法在目前 Grilling Session 內完成。

06 · TRUST & RISK

外部 artifact 採用或高風險操作

Signal：外部輸入將進入系統，或下一動作可能破壞 shared state。
